# myAsset — 자산관리 웹사이트 (UI 프로토타입)

계좌·종목·자산군 기준으로 내 자산을 한눈에 보는 웹사이트입니다.
지금은 **UI 확정 단계**라서 실제 DB(Supabase)나 증권사 API 없이 **가상(Mock) 데이터**로 실제 서비스처럼 동작합니다.

## 실행 방법 (가장 쉬운 방법)

1. 이 폴더의 `index.html` 파일을 **더블클릭**하면 브라우저에서 열립니다.
2. 위쪽 메뉴로 5개 화면을 오갈 수 있습니다.

| 화면 | 파일 | 하는 일 |
|---|---|---|
| Dashboard | `index.html` | 전체 요약 (조회만) |
| 자산군 현황 | `groups.html` | 7개 자산군 기준 현황 (조회만) |
| 계좌 현황 | `accounts.html` | 계좌별 보유 종목 현황 (조회만) |
| 이력 | `history.html` | 매일 08:00 스냅샷으로 저장된 과거 현황 |
| 계좌/자산관리 | `manage.html` | 자산군별 종목 매핑 확인 + 자산 구성 관리 / 계좌 관리(수정·엑셀 다운로드) / 엑셀 업로드 |

- 오른쪽 위 **[원화환산] [달러환산] [한국=원화 / 미국=달러]** 로 통화 표시를 바꿉니다. (기본값: 원화환산)
- 화면에서 바꾼 내용은 **이 브라우저에만** 저장됩니다. 처음 상태로 돌리려면 오른쪽 위 **[Mock 초기화]** 를 누르세요.
- 인터넷이 연결되어 있어야 차트(Chart.js)와 엑셀 기능(SheetJS)이 동작합니다.

## 자동 점검

`tools/selftest.html` 을 열면 스크립트의 Mock 테스트 시나리오(환차손익 계산, 자산군 이동, XLSX 업로드 등)를 자동으로 확인합니다.
실제 화면의 데이터에는 영향을 주지 않습니다.

## 폴더 구조

```
index.html / groups.html / accounts.html / history.html / manage.html   화면 5개
css/style.css            디자인
js/config.js             자산군 7개 등 공통 설정
js/format.js             숫자·날짜 표시 형식 (₩, $, %, 색상)
js/calc.js               손익·환차손익 계산
js/dataService.js        ★ 모든 데이터 읽기/쓰기 (나중에 Supabase 연동 시 이 파일만 교체)
js/common.js, render.js, charts.js   공통 화면 부품
js/pages/*.js            화면별 코드
mock/*.js                가상 데이터 (계좌, 종목, 보유, 현재가, 환율, 과거 스냅샷, 외부 종목 목록)
mock/sample_holdings*.xlsx   업로드 검수용 예시 파일 (정상 / 오류 포함)
tools/build-sample-xlsx.ps1  위 예시 xlsx 다시 만들기
```

## 다음 단계 (UI 확정 후)

DB 스키마 → Supabase → 로그인/보안(RLS) → 계좌·종목·보유 저장 → 가격·환율 API → 08:00 자동 스냅샷 → 이력 연동 → XLSX 서버 검증 순서로 연결합니다.
API 키 같은 비밀 값은 화면 코드(프론트엔드)나 GitHub에 절대 넣지 않습니다.

> 모든 금액·수량·계좌명은 가상 값입니다. 종목코드와 가격은 예시입니다.
